# Doc ROI Calculadora

Solucion web estatica para guiar a alumnos y perfiles ejecutivos en la construccion de un caso ROI + LTV + Customer Equity.

## Que incluye

- Cuestionario guiado por fases: contexto, audiencia, ingresos, OPEX, CAPEX, LTV y Customer Equity.
- Calculo vivo de ROI, VAN, Payback, beneficio neto, LTV diferencial e impacto total sobre cartera.
- Marco KAI ROI para explicar Customer Equity Activo.
- Informe final imprimible desde el navegador para guardar como PDF.

## Como usarla

La aplicacion se abre desde `index.html` y esta preparada para GitHub Pages. No requiere servidor, base de datos ni instalacion.

Los datos se guardan localmente en el navegador mediante `localStorage`.
